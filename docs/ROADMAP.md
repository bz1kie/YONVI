# Дорожная карта YORI

## На 10 ноября 2026
- **1.4 — локальный демопрототип:** React + TypeScript, UI Kit, Йори-енот, каталог, поиск, избранное, карточка товара, создание лота, круги, демонстрационная модерация, темы и мобильная навигация.
- **GitHub:** репозиторий `bz1kie/YORVI` инициализирован проектной документацией; исходный код демоверсии нужно выгрузить отдельно.

## P0 — базовый репозиторий и качество
1. Публикация исходников и статических ресурсов 1.4.
2. Воспроизводимая сборка, lockfile, форматирование, lint и CI.
3. Замена устаревшего React 16 UMD на современный поддерживаемый React + Vite.
4. Unit/интеграционные тесты, скриншотные проверки UI, тесты мобильной навигации.

## P1 — backend MVP
1. PostgreSQL, миграции и seed демоданных.
2. Пользователи, объявления, фотографии и категории.
3. Один лот — много размещений, независимая модерация и общие глобальные статусы.
4. Серверные роли, аудит и антиспам.
5. API для каталога, избранного, продавца и кругов.

## P2 — MAX и пилот
1. Проверка актуальной документации MAX Bot API/Mini App и условий доступа.
2. Вход, привязка аккаунта и deeplink на объявление.
3. Уведомления и разрешённая публикация/распространение.
4. Тестирование и пилот в 3–5 сообществах одного города.
5. Метрики просмотров, контактов, успешных продаж и удержания.

## P3 — монетизация и расширение
Платное продвижение, Pro кабинеты продавцов, инструменты администраторов кругов, аналитика, затем новые города и категории. Ни платежи, ни защищённая сделка не заявляются как готовые.

## Критерий реального MVP
Два пользователя на разных устройствах видят одну серверную карточку; продавец создаёт лот, разные модераторы независимо одобряют его в своих кругах, покупатель связывается с продавцом, после продажи лот исчезает со всех активных витрин. Все права и состояния обеспечиваются сервером, не только UI.
