# React ↔ Fastify: серверные сценарии YORVI

## Статус
В `apps/web/src/ServerWorkspace.tsx` добавлен **изолированный от демо** клиентский раздел «Сервер · тест» для создания объявлений, их редактирования, отправки в круги, модерации и отметки «Продано». Основной каталог YORVI 1.4 остаётся визуальным прототипом с гибридным чтением публичного API.

**Безопасность:** раздел «Сервер · тест» доступен только при `import.meta.env.DEV` в Vite. При production-сборке ссылка и экран недоступны. Сервер игнорирует тестовую авторизацию при `NODE_ENV=production` или без `ALLOW_DEMO_AUTH=true`.

## Локальный запуск

Требуются Node.js 22+, npm, PostgreSQL 17 и Docker.

```bash
npm install
docker compose up -d db
# Примените миграции и создайте локального тестового пользователя/круг
npm run db:prepare  # если команда определена; иначе: node scripts/prepare-db.mjs
```

Терминал 1 (Linux/macOS):
```bash
NODE_ENV=development ALLOW_DEMO_AUTH=true npm run dev:api
```
Терминал 2:
```bash
npm run dev:web
```
Откройте http://localhost:5173 и в меню «Для разработки» выберите **Сервер · тест** (на мобильном — кнопка настройки в шапке).

Тестовый пользователь: `11111111-1111-4111-8111-111111111111`.
Тестовый круг: `22222222-2222-4222-8222-222222222222`.

Для PowerShell настройте переменные `$env:NODE_ENV='development'; $env:ALLOW_DEMO_AUTH='true'` перед запуском API.

### Проверка сценария
1. Создайте объявление, укажите цену, описание и круг.
2. После подтверждения формы появится серверный лот с заявкой `pending`.
3. Откройте «Модерация кругов» и одобрите объявление.
4. Откройте публичный каталог — товар станет доступен после обновления.
5. Отредактируйте цену/описание — прежнее одобрение сбросится.
6. Повторно одобрите размещение и затем отметьте товар «Продано».
7. В публичной выдаче проданный лот не показывается.

Оба интерфейса используют общие визуальные токены YORVI, но пока **не являются единой продакшен-админкой**. Данные в демо-каталоге могут отличаться от серверных.
