# YORVI — маркетплейс объявлений и сообществ в MAX

**YORVI (Йорви)** — проект локального маркетплейса: одно объявление может размещаться в нескольких тематических или городских сообществах («кругах»), оставаясь одной сущностью с общими статусами и историей.

**Слоган:** «Нашёл — твоё».

> **Статус на 10.11.2026:** интерактивный демонстрационный прототип **YORVI 1.4** подготовлен локально на React + TypeScript. Этот репозиторий первоначально был пустым; сейчас сюда внесена проектная документация. **Исходники 1.4 пока не опубликованы в репозитории**. Реальных интеграций MAX, сервера, платежей и продакшен-авторизации ещё нет.

## Концепция

- Покупатели находят вещи по категориям, городу, цене, состоянию и сообществам.
- Продавцы создают **одно объявление**, а затем выбирают несколько кругов для размещения.
- Модераторы каждого круга независимо решают, показывать ли объявление своей аудитории.
- Изменение глобального статуса («продано», «архив») синхронно влияет на все витрины.
- Администратор круга управляет правилами, модераторами и внешним оформлением витрины.
- MAX планируется использовать как точку входа: бот + Mini App, с возможностью самостоятельной веб-версии.

## Дизайн и персонаж

- **Маскот:** Йори — **енот**, а не робот; чёрная кепка с Y, лаймовое худи, наушники.
- **Основные цвета:** графит `#0D0F12`, лайм `#C8FF4D`, белый `#FFFFFF`, серый `#8B9099`.
- Основные экраны: главная, каталог, карточка товара, размещение, круги, избранное, профиль, модерация.
- Адаптивный интерфейс с мобильной нижней навигацией, светлой и тёмной темой.

## Что реализовано в локальном прототипе 1.4

Каталог, поиск и фильтры; избранное; карточки товаров с иллюстративными фотографиями; создание/редактирование объявлений; выбор нескольких кругов; демонстрационная модерация; общий статус «Продано»; мобильная навигация; фирменная дизайн-система. Данные хранятся **только в браузере (localStorage)**.

**Ограничения:** отсутствуют реальные аккаунты и права, единая серверная база, модерация на сервере, загрузка на S3, MAX Bot API / Mini App, платежи и настоящий чат. Текущая демосборка использует устаревший React 16 UMD — требуется модернизация.
