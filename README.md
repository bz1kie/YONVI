# YORVI — маркетплейс в MAX

**YORVI («Нашёл — твоё»)** — будущий маркетплейс объявлений с ботом и Mini App в MAX. Единое объявление может размещаться сразу в нескольких витринах («кругах») с независимой модерацией. Фирменный маскот — **Йори-енот**.

## Состояние проекта · 10.11.2026

**YORVI 2.0 alpha — начало разработки.** Репозиторий теперь содержит начальный monorepo-каркас: `apps/web` (React + Vite), `apps/api` (Fastify), `packages/shared` (типы), `packages/database` (PostgreSQL schema), Docker Compose и доменные unit tests.

**Важно:** это ещё не полноценный сайт. В GitHub лежит упрощённый placeholder интерфейса, **полная версия React-прототипа 1.4 и расширенные Fastify routes входят в отдельно подготовленный ZIP**, пока не перенесённый сюда. API и UI ещё не подключены друг к другу. Не подключены реальные MAX auth, серверная модерация и платежи. Новые npm-пакеты пока не установлены и полная сборка не проверена из-за отсутствия доступа к npm registry в среде подготовки.

## Технологии
React + TypeScript + Vite · Fastify + TypeScript · PostgreSQL · npm workspaces · Node.js 22 · Docker.

## Локальный запуск (после скачивания репозитория)
```bash
npm install
docker compose up -d db
npm run dev:web
# второй терминал: npm run dev:api
npm test
```

Web: http://localhost:5173 · API: http://localhost:3001/health

## Ближайшие задачи
1. Перенести полный React UI 1.4 с ассетами и восстановить сборку через Vite.
2. Подключить UI к REST API и PostgreSQL.
3. Реализовать серверную регистрацию, права модераторов, загрузку фотографий, версионирование.
4. Подключить MAX Bot/Mini App только после проверки HMAC и разрешённых сценариев.
5. Подготовить e2e/интеграционные тесты и закрытый пилот.
